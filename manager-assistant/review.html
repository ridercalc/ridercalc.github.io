手機 App 內的真實操作示範

  1. 開啟管理員助手（封測），閱讀自動操作告知。可以拒絕、重新閱讀，再決定是否同意。
  2. 同意後按頂端「示範環境（假資料／免智生活帳號）」。
  3. 按「辨識範例標籤」。App 真的在本機執行 OCR，不是預填識別結果。檢查號碼、樓層、姓名、條碼，可自行修正。
  4. 按「開啟無障礙設定」，啟用管理員助手（封測）自動填寫，再返回。離線示範需 Android 11 以上。
  5. 按「開始自動登記示範」。正式登記引擎會辨識畫面、選擇郵件種類／位置／戶別、填寫姓名、核對並送出到示範頁。
  6. 看見「示範完成」才代表引擎已讀到成功畫面。可停止、返回核對重試。離開示範畫面停止本次示範。

示範從標籤 OCR 與人工核對後的物品表單開始。它不測試智生活登入、相簿交接或其伺服器，不代表已驗證第三方正式環境。示範不修改正式社區或包裹紀錄、不列印，不需要提供帳密。

English reviewer instructions

The app contains an openly labelled offline demo with synthetic data. No login, membership, location or third-party account is required for this demo. The demo is available to all users, not hidden behind reviewer detection. It does not impersonate SmartLife.

  1. Launch the submitted Manager Assistant build. Read the prominent accessibility disclosure. Rejecting leaves automation disabled; “重新閱讀告知” lets you reopen the disclosure. Accept with “我同意上述資料存取與自動操作”.
  2. Tap the top “示範環境（假資料／免智生活帳號）” button.
  3. Tap “辨識範例標籤” to run actual on-device OCR on the generated synthetic label. Review and edit the house number, floor, name and parcel code. Sample: house 903, floor 7, name 陳小雲. No result is substituted if OCR fails. The sample has no actual barcode, so the barcode field remains blank. Its fictional address is parsed from OCR text against the demo-only 901/903/905 range; this is not evidence of production address-range recognition.
  4. Use “開啟無障礙設定” to enable this app's accessibility service, then return. The offline screenshot-based demo requires Android 11 or later.
  5. Tap “開始自動登記示範”. The production registration state machine and screen OCR act on a bundled WebView. It selects the mail type, location, group, floor and household, enters the name and submits only to local demo memory. The demo floor grid exposes all 15 floors; it does not validate SmartLife's scrolling menu.
  6. The bottom status “示範完成” confirms that the automation engine observed the result. “停止示範／返回核對” stops the run. Leaving the demo stops automation. Repeat as needed; each attempt stops after a maximum of three minutes.

Scope: this is an after-label-review registration demonstration, not evidence of SmartLife login, photo-picker integration, server access, community discovery, package tally or a physical printer. Production integration requires the user's separately authorised SmartLife account. Those external flows cannot currently be fully exercised through this demo; additional access or evidence may be requested.
